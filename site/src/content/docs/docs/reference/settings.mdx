Settings are one scrollable page with sub-pages for **Dictionaries**, **Anki** and **AI explanations**. The back
button or gesture returns to the list.

## Dictionaries and Anki

- **Dictionaries** — install Jitendex, JMdict, JMnedict, Pixiv Light or Kanjium pitch accents with one tap,
  import Yomitan zips from files or Google Drive (your own Drive or a shared file/folder link), drag cards to reorder priority, check for updates, inspect entries,
  delete. Name dictionaries such as JMnedict start at the bottom so they never shadow vocabulary.
- **Anki** — backend (AnkiDroid or AnkiConnect), URL, deck, note type, tags, whether to attach
  the screenshot, the picture's maximum height (default 462 px, 0 = original), a **Test
  connection** button, and a per-note-type **Fields** editor that overrides name matching.

## Language and OCR (multilingual development branch)

- **Study language** selects dictionary boundaries, preprocessing and deinflection independently of the OCR engine.
- **Engine** — Auto, meikiocr (Japanese game text), ML Kit or PaddleOCR ONNX.
- **ML Kit script** — Latin, Chinese, Japanese, Korean or Devanagari. Latin/Japanese are bundled;
  the other three require Google Play services and an initial model download. Catalog entries
  share script models and keep Google's supported/experimental/mapped categories.
- **PaddleOCR** — as in Chimahon, every recognizer is its own engine option (Latin Tiny,
  Multilingual, Cyrillic, Arabic, Greek, Korean, or the study language's), and **PaddleOCR
  detector** (Tiny or Small) is always shown and shared by all of them. Picking one downloads the
  detector and recognizer it needs. **PaddleOCR models** lists every model with its status, size
  and Download/Delete. Models are checked with SHA-256 and run locally after installation.
- **Download meikiocr models (31 MB)** — until installed, the Japanese path uses ML Kit.
- **Two-pass OCR (ML Kit)** — optionally re-read detected lines at higher resolution.
- **Filter non-study-language lines** — remove background UI noise using the chosen text profile.
- **Live text window** — show the floating feed of new lines while auto OCR runs.
- **Tap text on screen to look it up** — the invisible screen dictionary layer.
- **Pause the video while looking up** — media-key pause/resume around a lookup.
- **Auto OCR interval** — 200–2000 ms (default 400 ms). Lower catches short lines sooner; higher
  saves battery.

## AI explanations (multilingual development branch)

AI is off by default. Bring your own key through one **Custom (OpenAI-compatible)** provider:
endpoint (any chat-completions URL: OpenAI, OpenRouter, DeepSeek, Gemini's OpenAI endpoint, a
local server), API key, model ID, OpenRouter provider routing/slugs/fallbacks, thinking mode and
effort, and a custom request-body JSON. Then the prompts, temperature and behaviour: *Generate on
lookup*, *Real time response*, *Cancel unfinished requests* and *Use AI when no dictionary entry
exists*. *Test connection* checks the saved setup. Keys are encrypted using Android Keystore and
excluded from backups.

Once enabled, the explanation appears at the **top of the lookup popup, above the dictionary
entries**, as in Yomitan: the selected original word and its sentence go to your endpoint. **↻**
regenerates, **Cancel** stops the request, and closing/changing the lookup cancels it (unless
*Cancel unfinished requests* is off). Dictionary results remain available without AI. Map a
note-type field to **AI explanation** in Cards → Fields to put the explanation on the card;
**Popup selection** adds the text you selected in the popup. The **Anki** button in the AI box
sends the explanation as plain text to the word's card: it fills that field on the existing note,
or adds the card if the word isn't in Anki yet.

These additions still need physical-device validation; build/test evidence is recorded in the
repository's `docs/integration-state.md` and `docs/multilingual.md`.

## Cards

- **Glossary** — what the card's definition holds, like Yomitan's markers:
  - *First dictionary only* (default) — only your highest-priority dictionary (`{glossary-first}`),
    the one at the top of *Settings → Dictionaries*.
  - *All dictionaries, unnamed* — every dictionary's definitions without the dictionary
    names (`{glossary-no-dictionary}`).
  - *All dictionaries, named* — each dictionary under its name (`{glossary}`).

  In the lookup popup, tap a dictionary's name (*Use on card*) to put only that dictionary on
  that word's card instead.

## Sentence audio

- **Capture game audio** — playback capture through MediaProjection. Requires the microphone
  permission and Android 10+.
- **Microphone fallback** — record the microphone when device audio is silent (DroidDeck,
  Netflix). Works with the speaker on; records nothing with headphones.
- **Noise suppression** — Android's voice noise filter on the mic session.
- **Speaker correction EQ** — high-pass plus a per-device curve measured from the tablet's own
  speaker, so mic clips are less tinny. Includes a **Measure** action.
- **Compressor** — evens out loud peaks before normalization.
- **Normalize volume** — bring every clip to the same loudness.
- **Word audio** — fetch pronunciation from JapanesePod101/Jisho for Japanese study; other languages use only the custom audio URL.
- **Custom audio URL (optional)** — tried first; `{term}` and `{reading}` are replaced.
- **Replay buffer** — 1–10 minutes (5 by default, about 2.9 MB of memory per minute).
- **Start offset / End offset** — 0–3000 ms of audio kept around the line.
- **Trim silence (experimental)** — VAD trim. Off by default because loud music can clip speech.

## About

The About card shows the app version and credits. The full list is in
[Credits](../reference/credits/).

- **Check for updates** — asks GitHub for the newest release; if it is newer, **Update to vX.Y.Z**
  downloads it and opens Android's installer.
- **Check for updates automatically** (default on) — the same check each time the app opens. The
  update itself always waits for your tap.

:::note[Values change between releases]
This page describes the current release. If a setting is missing, your version is older. The
in-app labels are the source of truth.
:::
